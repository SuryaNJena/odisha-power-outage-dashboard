#   requests           - Kavach scraper + Open-Meteo + Flink REST health checks
#   beautifulsoup4     - reused by the repository scrap.py (table extraction)
#   lxml               - pandas.read_html backend used by scrap.py
#   pandas             - reused by the repository scrap.py (DataFrame -> CSV)
#   numpy              - pandas 2.1.x is built against the NumPy 1.x ABI
#   kafka-python-ng    - KafkaAdminClient + KafkaProducer for all topics
